# Raybod Akbarlou — Portfolio

## اجرا روی سیستم شما
همین فولدر را باز کنید یا با یک لوکال سرور اجرا کنید:
```
npx serve .
```

## انتشار
- **GitHub Pages**: محتوای این فولدر را در ریشه یک ریپازیتوری push کنید و Pages را از شاخه `main` فعال کنید.
- **Netlify**: کل فولدر را Drag & Drop کنید یا ریپازیتوری را متصل کنید (Build command خالی، Publish directory: `.`).

## نکات
- عکس پروفایل و تمام فاویکون‌ها از تصویر آپلودشده شما ساخته شده‌اند (`assets/profile.png`, `assets/icons/`).
- دکمه «دانلود رزومه» به مسیر `assets/Raybod-Akbarlou-Resume.pdf` اشاره می‌کند — فایل رزومه خودتان را با همین نام در پوشه `assets` قرار دهید تا فعال شود.
- لینک یوتیوب در فوتر فعلاً placeholder است (`#`)؛ لینک واقعی کانال خود را در `index.html` جایگزین کنید.
- زبان سایت با دکمه FA/EN در ناوبری قابل تغییر است و در مرورگر ذخیره می‌شود.
